# CFTR_FOOD_ALLERGENS
This repositoy contains the code for the various analyses employed in the realm of the study 'Cystic Fibrosis is associated with IgG4-dominated antibody responses to selected food allergens'.
Some of the code provided in this repository is written in R, some in python.
We hope that adding the code to the supplement is of use to the community. In case of questions, please reach out to Dr. Marc Emmenegger (marc.emmenegger@usb.ch or marc.emmenegger@gmail.com).
