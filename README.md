# CFTR_FOOD_ALLERGENS
This repositoy contains the code for the various analyses employed in the realm of our study on the immune responses to allergens in persons with Cystic Fibrosis.
Some of the code provided in this repository is written in R, some in python, and all of the code was written in order to support the study mentioned above. The following people were crucially involved in this work by contributing code:
1. Dr. Falko Noé and Dr. Hubert Rehrauer, Functional Genomics Centre Zurich (FGCZ): Created the pipeline to analyse data of the B cell receptor repertoire sequencing.
2. Dr. Natalia Zajac, FGCZ (currently Max Planck for Evolutionary Biology): Created code to analyse the sequencing of the CFTR gene in peanut allergy patients.
3. Dr. Andra Chincisan, University Hospital Zurich (currently Van Lanschot Kempen): Created code to access hospital-wide research databases containing patient data and implemented queries, statistical tests, and visualisations.
4. Dr. Marc Emmenegger, University Hospital Zurich (currently University Hospital Basel): Created code to statistically test and visualise data from numerous datasets contained in the sutdy.

We hope that adding the code to the supplement of the manuscript is of use to the community. In case of questions, please reach out to Dr. Marc Emmenegger (marc.emmenegger@usb.ch or marc.emmenegger@gmail.com).
